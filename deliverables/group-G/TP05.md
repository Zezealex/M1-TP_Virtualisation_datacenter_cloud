PARTIE 8
--------
Active Directory -  VM - Nécessite un kernel Windows dédié et une isolation stricte

Nginx stateless - LXC - Très léger, s'initialise instantanément et consomme un minimum de ressources pour du trafic HTTP/S

PostgreSQL critique - VM - Garantit des performances E/S stables, une gestion stricte du cache RAM et évite les kernel panics partagés

Runner CI - LXC - Idéal pour le cycle de vie court  et la faible empreinte mémoire.

Docker host - VM - Évite les conflits de stockage (OverlayFS) et les failles de sécurité liées à l'imbrication

DNS cache - LXC - Service réseau simple, non persistant et ultra-léger.

Appliance propriétaire - VM - Les appliances  fournissent leur propre OS/Kernel modifié indispensable à leur support.

Serveur Windows    VM    Proxmox ne peut pas exécuter de conteneurs Windows en natif.

Question 3 : ce schéma représente la création de VM ou conteneurs (LXC) à partir d'un modèle de base

Question 4 : Non, il sert uniquement à le configurer automatiquement lors du tout premier démarrage de la machine virtuelle (nom d'hôte, utilisateurs, clés SSH, réseau)

Question 5 : Les avantages principaux
• Accès immédiat et sans mot de passe : Dès que la VM démarre, vous pouvez vous y connecter en SSH sans avoir à taper de mot de passe.
• Sécurité renforcée : Les clés SSH sont beaucoup plus difficiles à pirater
• Désactivation des mots de passe : Cela permet souvent de bloquer complètement la connexion par mot de passe sur la VM tout en gardant un accès administrateur.
